# Contributing

Anyone can change any path. CI and review are the gates.

1. Branch off `main`.
2. Open a pull request into `main`.
3. Wait until the **Check / check** workflow is green. It runs `npm run check`: typecheck, lint, unit tests, and a production build.
4. Get a review.
5. Squash merge into `main`.

Run `npm run check` on the branch before you ask for review.
